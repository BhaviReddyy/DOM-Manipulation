# DOM-Manipulation

This project demonstrates basic DOM manipulation by dynamically adding list items and styling them based on their order.

## 📌 Task 2: Basic DOM Manipulation

### ✔ Requirements Completed:
- A `<ul>` with three initial `<li>` items.
- A button labeled **"Add Item"**.
- When the button is clicked:
  - A new `<li>` is added to the list.
  - If the newly added item number is **odd** → it is styled **bold + blue**.
  - If the item number is **even** → it is styled **italic + red**.

### 📂 Files Included
- `index.html` — Contains the HTML structure.
- `script.js` — Contains JavaScript code for adding and styling list items.

### 🚀 How to Run
Open **index.html** in any browser and click the **Add Item** button to see the DOM update live.
